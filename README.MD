# ⚡ Digital Business Card - Neon Edition

Este é um projeto de **Cartão de Visitas Digital** interativo, desenvolvido para praticar a manipulação do DOM (Document Object Model) e estilização avançada com CSS. O projeto apresenta um visual "Dark Mode" com detalhes em Neon (Chartreuse).

## 🚀 Funcionalidades

- **Atualização em Tempo Real:** O nome exibido no cartão muda instantaneamente conforme o usuário digita no campo de entrada.
- **Estado Padrão:** O cartão possui um nome reserva caso o campo seja limpo.
- **Design Responsivo:** Adaptado para visualização em dispositivos móveis e desktop.
- **Efeitos de Interação:** Botões com efeitos de `hover` e transições suaves.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica do projeto.
- **CSS3:** Estilização com Flexbox, efeitos de transição e sombras neon.
- **JavaScript:** Lógica para captura de eventos de input e manipulação dinâmica de texto.
- **Git & GitHub:** Versionamento e hospedagem via GitHub Pages.
